# 📊 Excel Claims & Vehicle Analysis Dashboard

This folder contains the documentation and references for my foundational Excel project, focused on insurance claims and vehicle risk distribution.

## 📌 Project Overview
* *Objective:* Analyze insurance claims data across various vehicle models, calculate key metrics like claim rates, and build an interactive dashboard using foundational spreadsheet techniques.
* *Key Techniques Used:* Data cleaning, relational lookups (VLOOKUP), Pivot Tables, and conditional formatting.
* *Key Findings:* Identified high-risk vehicle models and established the relationship between policy volumes and claim counts.
