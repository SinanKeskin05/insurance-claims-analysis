# 📊 Power BI Insurance Claims & Risk Analysis

This folder contains the interactive Power BI dashboard developed for the insurance risk and portfolio analysis project.

📌 **Project Overview**

* **Objective:** Visualize key insurance metrics, track claim rates across vehicle and demographic segments, and provide an interactive executive summary using Power BI.
* **Key Visualizations:** 
  * **KPI Cards:** Total Customers (59K), Total Claims (3,748), and Overall Claim Rate (6.40%).
  * **Engine Type Analysis:** Claim rate breakdown by various engine types (e.g., 1.2 L K12N Dualjet, 1.5 Turbocharged Revotorq).
  * **Fuel Type Analysis:** Comparative claim rates across CNG, Diesel, and Petrol vehicles.
  * **Vehicle Age Group Analysis:** Risk distribution segmented by vehicle age categories (New, Moderate, Old).
* **Interactive Features:** Dynamic cross-filtering and slicers for engine type, vehicle age group, and fuel type.

🔗 **Files in this Directory**

* `Insurance_Claims_Risk_Analysis_Dashboard.pbix`: The main Power BI report containing the interactive dashboard and data model.
