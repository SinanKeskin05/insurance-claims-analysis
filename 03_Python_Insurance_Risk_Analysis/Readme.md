# 📊 Python Insurance Claims & Risk Analysis

This folder contains the exploratory data analysis and data cleaning code for the insurance risk portfolio using Python.

📌 *Project Overview*

* *Objective:* Clean raw insurance data, handle missing values, and perform Exploratory Data Analysis (EDA) using Python to uncover risk patterns and claim distributions.
* *Key Techniques Used:* Data preprocessing, descriptive statistics, and data visualization with Pandas, Seaborn, and Matplotlib.
* *Key Findings:* Analyzed feature correlations, identified outlier claim amounts, and visualized risk distributions across demographic and vehicle segments.

🔗 *Files in this Directory*

* insurance_analysis.ipynb: Jupyter Notebook containing the full data analysis workflow.
* insurance.csv: The cleaned dataset containing 58,592 records.
